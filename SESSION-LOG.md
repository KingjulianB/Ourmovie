# Ourmovie Session Log

Chaque session de travail ajoute une ligne ici — la plus récente en
dernier. Deux raisons de garder ce fichier : un index rapide "quoi
quand" sur un projet qui s'étale sur plusieurs sessions, et un canal de
récupération en cas de pépin — les transcripts locaux de session
Claude Code conservent le contenu complet de chaque fichier lu et de
chaque appel `Write`/`Edit`, donc savoir quelle session a touché quel
fichier permet de retrouver ce contenu depuis le transcript même si la
copie de travail est perdue.
